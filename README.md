# EV Charging Network Performance Analysis

An Excel-based data analytics project exploring electric vehicle charging sessions, charging costs, energy consumption, and usage patterns across multiple US cities.

## Project Overview

This project analyzes an Electric Vehicle (EV) Charging Patterns dataset containing 1,320 charging-session records across five US cities.

The objective is to understand charging network usage, compare recorded charging costs across locations and user segments, and examine energy consumption patterns using an interactive spreadsheet dashboard.

## Business Problem

"How can the EV charging network optimize infrastructure placement, pricing strategies, and power utilization to maximize revenue while improving service availability across different cities and user demographics?"

## Project Objectives

- Analyze charging-session activity across different locations.
- Compare recorded charging costs by city and user type.
- Understand energy consumption across charger types.
- Explore charging activity by time period and day of the week.
- Compare session counts across EV models.
- Present the analysis through an interactive dashboard.

## Tools and Techniques

- WPS Spreadsheet / Microsoft Excel
- Data cleaning and preparation
- PivotTables and PivotCharts
- KPI summaries
- Interactive slicers and dashboard visualization
